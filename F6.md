# F6 - Operação Concluída

Durante a atividade aprendemos na prática como funciona o Code Review no GitHub.

Criamos branches, configuramos proteção na main e qa, revisamos o código por meio de Pull Request e identificamos problemas que precisavam ser corrigidos.

Depois das correções, o código foi revisado novamente, aprovado e integrado à branch qa.

A atividade mostrou a importância da revisão de código, da organização das branches e do trabalho em equipe.
