# F6 - Operação Concluída

Durante a atividade aprendemos na prática como funciona o processo de Code Review utilizando o GitHub.

Criamos branches para separar as etapas do desenvolvimento, configuramos proteção nas branches main e qa e utilizamos Pull Request para revisar as alterações antes do merge.

Também identificamos problemas no código, fizemos comentários durante a revisão, corrigimos os pontos encontrados e realizamos a aprovação antes do merge.

A atividade mostrou a importância da revisão de código e da organização do trabalho em equipe durante o desenvolvimento.
