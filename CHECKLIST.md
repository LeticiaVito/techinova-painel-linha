# Checklist de Code Review

- Verificar se o código funciona corretamente.
- Procurar erros ou possíveis bugs.
- Conferir se não existem senhas ou credenciais expostas.
- Verificar se os nomes de variáveis e funções estão claros.
- Conferir se alguma alteração pode quebrar funcionalidades existentes.
- Verificar se o código está organizado e fácil de entender.
